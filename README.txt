INSTRUCCIONES DE DESPLIEGUE - TERRAFORMER T-800 (GITHUB PAGES)

El diseño ha sido actualizado a una interfaz "Tactical Bio-Punk", fusionando una UI militar/técnica oscura con elementos crudos y colores ácido-neón.

PASOS:
1. Extrae todos los archivos de este ZIP.
2. Reemplaza el archivo 'terraformer_t800.glb' con tu modelo 3D real (asegúrate de que tenga el mismo nombre y extensión).
3. Reemplaza el archivo 'terraformer_t800.usdz' con tu modelo para iOS (opcional, pero necesario para AR en iPhone).
4. Reemplaza el archivo 'poster.png' con un render oscuro o técnico de tu modelo para que coincida con la estética.
5. Sube todos los archivos (incluyendo el index.html) a la raíz de tu repositorio en GitHub.
6. Activa GitHub Pages apuntando a la rama principal (main/master).
