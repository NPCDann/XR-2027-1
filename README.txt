Instrucciones para GitHub Pages:

1. Extrae todos los archivos de esta carpeta.
2. Reemplaza el archivo 'terraformer_t800.glb' con tu modelo 3D real (asegúrate de que tenga el mismo nombre y extensión).
3. Reemplaza el archivo 'terraformer_t800.usdz' con tu modelo para iOS (opcional, pero necesario para AR en iPhone).
4. Reemplaza el archivo 'poster.png' con una imagen representativa de tu modelo.
5. Sube todos los archivos (incluyendo el index.html) a la raíz de tu repositorio en GitHub para que GitHub Pages lo reconozca.
